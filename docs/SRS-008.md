# SRS-008 — Data Praktikum

Integrasi ini memakai aplikasi Expo dan konfigurasi Firebase di **root repo**. Jalankan perintah dari root yang berisi `App.tsx`, `package.json`, dan `firestore.rules`.

## Alur aplikasi

- **Asisten** membuka **Jadwal → Kelola data praktikum**. Buat kelas, daftarkan akun praktikan sebagai peserta, tambahkan jadwal mingguan, lalu buat sesi pada tanggal yang sesuai hari jadwal.
- **Praktikan** membuka **Jadwal → Lihat jadwal per kelas**. Akun yang sudah terdaftar dapat melihat jadwal dan sesi kelasnya. UID akun dapat disalin dari **Profil** untuk diberikan kepada asisten.
- Sesi yang sudah dibuka tetap tersedia untuk riwayat. Asisten pembuat sesi membuka dan menutup sesi melalui **Detail Sesi**. Kode QR diterbitkan saat sesi dibuka dan dihapus saat ditutup.
- Pengguna yang masuk melalui mode demo pengembangan memakai data lokal Sprint 1.

## Kontrak data

| Path Firestore | Isi |
| --- | --- |
| `users/{uid}` | Profil dan peran akun dari SRS-007 |
| `classes/{classId}` | Nama praktikum, kode kelas, dan jumlah data anak |
| `participants/{classId}~{uid}` | Keanggotaan peserta yang terhubung ke UID Firebase Auth |
| `classes/{classId}/schedules/{scheduleId}` | Hari, jam WIB, dan ruangan |
| `classes/{classId}/sessions/{sessionId}` | Jadwal, tanggal, modul, pemilik sesi, dan status |
| `sessionCodes/{classId}~{sessionId}` | Kode sementara yang bisa dibaca asisten |
| `attendance/{classId}~{sessionId}~{uid}` | Presensi yang sudah dikonfirmasi, dengan timestamp Firestore |

ID sesi yang dipakai tampilan, QR, dan relasi izin adalah `classId~sessionId`. Operasi CRUD subkoleksi menggunakan kedua ID dokumen secara terpisah. Aturan Firebase yang sama mencakup autentikasi, data praktikum, presensi QR, dan izin. Data dummy Sprint 1 tidak dimigrasikan. Isi kelas dan keanggotaan melalui layar asisten.

## Verifikasi sebelum deploy

```bash
npm ci
npx expo lint
npx tsc --noEmit
node tests/practicum.test.cjs
npx firebase-tools emulators:exec --only firestore --project demo-prakti-srs008-tests "node tests/firestore-rules.test.mjs"
```

Uji dengan asisten dan dua akun praktikan yang terdaftar di kelas berbeda. Tambah dan ubah data lewat asisten, buka ulang aplikasi, lalu cek setiap praktikan hanya melihat kelasnya. Uji buka dan tutup sesi, presensi dengan kode yang benar dan salah, pencabutan keanggotaan, daftar kosong, dan tombol **Coba lagi** saat koneksi gagal. Setelah pengujian lulus, pemilik proyek Firebase menerapkan `firestore.rules` dari root repo ke proyek tim.
